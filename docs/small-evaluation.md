# 六例业务小样本评测

固定任务见 `eval/small_tasks_v1.json`，每个只运行一次。它是人工编写的业务回归集，
采用一段已有授权的 12 秒 NASA 视觉素材，输入工程和中文字幕由评测脚本通过原生 API
建立；Agent 命令、英文译文、配音和视频均来自实际本地服务。素材来源记录沿用
`demos/earth_full_20261111/provenance.json`。这套结果不作为公共 benchmark 成绩。

| 分组 | 任务 | 独立检查 |
| --- | --- | --- |
| Agent | 按原片第 2–4 秒裁剪 | 原片绝对时间、两秒总长、来源及其他设置 |
| Agent | 只修改字幕 | 指定文字、字幕时间和样式、原片与已有竖屏画幅 |
| Agent | 中点拆分 | 两个各两秒片段、源范围连续、总长和画幅保持 |
| Agent | 两轮修改 | 首轮竖屏与指定字幕；次轮拆分并保留首轮要求 |
| 译制流程 | 两句中文翻译及配音 | 术语/数字/关键信息、6 秒音频窗口、实际导出 |
| 负向守卫 | 配音后修改字幕 | 音轨过时标志、导出 422、提示重配音、版本保持 |

每个正向用例导出真实 preview 视频，用 FFprobe 检查帧数、分辨率和音轨。
时间允许一个输出帧的误差，源连续性和保护字段按明确约束检查。
验收器的纯函数单测覆盖误裁中点、错源、断续、额外片段、画幅误改和数字丢失。
已完成的其他系统测试无需为本评测重复执行。

Agent、译制流程和负向守卫分别计数。失败保留原始观察结果；依赖未完成的任务标记
blocked。内部有界修复沿用当前产品配置，评测器不自动重发 Agent 写入请求，也不按
失败结果现场修改应用。节点时间、规划范围、恢复标志和导出耗时记录在独立报告里。
本轮不报告未采集的模型调用数、首次提案成功率或大样本统计结论。

翻译只做明示的关键信息/词项检查；忠实度、漏字与声音自然度仍需结合字幕和成片人工检查。
参考译文仅供评测器查看，不作为模型回答。报告保留这一待审项。

### 已定位的问题与处理顺序

1. **未请求修改时保留当前画布。** `apps/api/camcat/agent/graph.py` 的 `understand`
   每轮根据用户文本和原素材宽高调用 `choose_aspect_ratio`，没有沿用已有画布；
   `generate_commands` 随后生成 `UpdateCanvas`，`_canvas_for_ratio` 将比例转换为固定
   分辨率。该应用规则解释了本轮四个编辑任务共同出现的画布覆盖。
2. **修正绝对原片时间的裁剪。** 明确要求原片 2–4 秒时，结果仍保留旧的 1.056 秒起点，
   只缩短时长。报告记录了输入和实际源区间；具体规划/转换原因需继续定位。
3. **避免无关的工程结构变化。** 无字幕任务新增空字幕轨，严格保护检查判为失败。
   它没有可见字幕效果；拆分例的分辨率变化也保持了 16:9。两者应与竖屏变横屏、
   裁错内容分别解释。

本轮原始报告和评分保持冻结。后续修复应通过相同验收规则建立新 run，记录前后结果；
本轮没有据失败结果修改应用或启动重测。
